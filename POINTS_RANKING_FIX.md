# ONYX Points / Ranking Fix

- Gamemode points are derived only from the ONYX tier mapping.
- ELO/rating values are never displayed as website points.
- An unranked gamemode has 0 points.
- Overall points are the sum of the player's tested kit tier points.
- Leaderboard uses competition ranking: equal points receive the same rank number (1, 1, 3 style).
